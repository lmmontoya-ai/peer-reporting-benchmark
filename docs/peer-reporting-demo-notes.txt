Peer-reporting P1: two-minute demo framework

This AI-assisted artifact is a factual demo outline for the project or video.
It is not an answer to the submission form. The form requires a human to write
its answers without AI. Do not paste this outline into the form or describe it
as human-authored. No form is submitted by these scripts.

This is a framework, not a completed-results claim. Fill the counts only from a
closed, fetched archive after the verified summary command succeeds.

0:00-0:25
We ask whether an observer carrying out an ordinary inventory task raises a
private, evidence-supported concern about a fictional approval breach. N is the
number of scripted peers, excluding the observer. K is the number of verified
participants in the shared incident. A concern about a signer's prohibited action
can identify the shared incident. The focal-operation endpoint separately asks
whether the observer identifies the original submit_request operation.

Show the public packet and approval records in the existing evidence export.

0:45-1:10
Open the summary's collection table. Read its planned and status counts aloud.
Keep the 9 smoke assignments separate from the 216 collection assignments.
Compatibility checks established transport support, not reporting propensity.
Show report attempts beside accepted private reports, task submissions, termination
and resource observations. An attempted call can fail; an accepted report can be
incorrect. Unknown resource use is unavailable, not zero.

1:10-1:35
Open one verified trace chosen by a declared, outcome-independent rule, such as
the first archived collection assignment in planned order. In the existing live
export show the public records, private report, observer outputs and termination.
If there is no archived collection assignment, show the status and reason instead.
State which semantic outputs await human review. Supported shared-incident and
focal-operation concern are distinct endpoints. Unsupported material claims must
be reviewed across private reports, public posts and final answers. A correct
concern does not erase a false claim elsewhere.

1:35-2:00
Show cell counts and all-assigned bounds in summary.json. The two finite fixture
blocks are different stimuli, not identical independent repetitions. K changes
evidence as well as participation. This pilot does not establish a population
threshold, diffusion of responsibility, peer-pressure resistance or costly
whistleblowing. Final accuracy requires the specified human review, including
independent second review and adjudication where required.
